# DIRETÓRIO DE MÍDIA — BARBEARIA IMPERIAL

Copie os arquivos de mídia aprovados exatamente com estes nomes neste diretório (`/public/media/`):

1. `hero-desktop-scroll.mp4` (1920x1080, horizontal, 8 segundos, codificação H.264 All-Intra recomendada para scrubbing instantâneo sem atraso de keyframes)
2. `hero-mobile-lightweight-landscape.mp4` (1280x720, horizontal, versão leve para conexões e dispositivos móveis)
3. `hero-poster.webp` (Poster do primeiro frame do vídeo para pré-carregamento)
4. `ritual-do-mestre.webp` (O profissional trabalhando com foco nas mãos e navalha)
5. `corte-degrade.webp` (O resultado do corte masculino com acabamento suave)
6. `barba-acabamento.webp` (O acabamento da barba com toalha quente e navalha)
7. `instrumentos-premium.webp` (Composição editorial dos instrumentos de precisão)
8. `ambiente-completo.webp` (Vista panorâmica do salão em madeira nobre e iluminação 2700K)
9. `experiencia-final.webp` (O atendimento concluído entre cliente e mestre barbeiro)

O sistema possui fallback editorial automático: caso algum arquivo ainda não tenha sido adicionado, um quadro com a estética visual da marca e informações de caminho é renderizado sem quebrar o layout.
